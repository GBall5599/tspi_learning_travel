# 第 3 课实操命令：第一个用户态程序

> 完成日期：2026-07-25

## 使用规则

MobaXterm 串口粘贴多行内容容易出错。以下命令请**每次只执行一条**，不要整段一次粘贴。

## 1. 创建基础脚本

```sh
cd /userdata
```

```sh
echo '#!/bin/sh' > hello.sh
```

```sh
echo 'echo "Hello from RK3566!"' >> hello.sh
```

```sh
echo 'echo "current user: $(id -un)"' >> hello.sh
```

```sh
echo 'echo "current pwd:  $(pwd)"' >> hello.sh
```

```sh
echo 'echo "current time: $(date)"' >> hello.sh
```

## 2. 查看并运行

```sh
cat /userdata/hello.sh
```

```sh
ls -l /userdata/hello.sh
```

```sh
sh /userdata/hello.sh
```

如果脚本中误把 `date` 写成 `data`，修正：

```sh
sed -i 's/$(data)/$(date)/' /userdata/hello.sh
```

再次运行：

```sh
sh /userdata/hello.sh
```

## 3. 添加执行权限

```sh
chmod +x /userdata/hello.sh
```

```sh
ls -l /userdata/hello.sh
```

```sh
./hello.sh
```

## 4. 检查退出状态码

```sh
./hello.sh
```

```sh
echo "exit code=$?"
```

制造一次失败并检查状态码：

```sh
ls /not_exist
```

```sh
echo "exit code=$?"
```

## 5. 增加命令行参数

以下仍然每次执行一条：

```sh
echo 'echo "argument count: $#"' >> /userdata/hello.sh
```

```sh
echo 'echo "first argument: $1"' >> /userdata/hello.sh
```

查看末尾内容：

```sh
tail -n 10 /userdata/hello.sh
```

带一个参数运行：

```sh
./hello.sh lesson3
```

带三个参数运行：

```sh
./hello.sh one two three
```

## 6. 常用检查命令

```sh
cat /userdata/hello.sh
```

```sh
tail -n 4 /userdata/hello.sh
```

```sh
tail -n 10 /userdata/hello.sh
```

```sh
ls -l /userdata/hello.sh
```

## 7. 不建议在 MobaXterm 串口中使用

以下类型的命令在本次实践中容易被多行粘贴破坏：

```sh
cat > hello.sh <<'EOF'
```

以及包含 `\n` 的长 `printf` 命令。建议改为 `vi` 或上面的单行 `echo` 命令。

## 8. 最终 SSH 验证

```sh
cd /userdata
```

```sh
./hello.sh ssh
```

预期看到：

```text
current user: root
current pwd:  /userdata
argument count: 1
first argument: ssh
```
