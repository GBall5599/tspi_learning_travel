
## 3. 下一课：第一个 C 用户态程序与交叉编译

### 3A. 先补概念

在写代码前理解：

```text
hello.c
  → 预处理
  → 编译
  → 汇编
  → 链接
  → AArch64 ELF 可执行文件
  → 上传到 RK3566
  → Linux 加载并运行
```

需要区分：

- 源代码与可执行文件；
- 本机编译与交叉编译；
- x86-64 与 AArch64；
- 编译器、链接器和 C 运行库；
- 静态链接与动态链接；
- ELF 文件与 Windows PE 文件。

### 3C. 下一步：第一个 C 程序

计划创建：

```c
#include <stdio.h>

int main(void)
{
    printf("Hello from RK3566!\n");
    return 0;
}
```

要求：

- 代码先保持最小；
- 使用标准 `int main(void)`；
- 检查编译命令和返回值；
- 不引入不必要依赖。

### 3D. 上传与运行

```text

→ echo $?
```
