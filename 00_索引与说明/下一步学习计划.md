### 第 3 课：第一个用户态程序 🔜

**目标：**

```text
完成最小“开发闭环”
```

建议分两小步：


#### 3A. Shell 脚本

```bash
/userdata/hello.sh
```

内容示例：

```bash
#!/bin/sh
echo "hello from taishanpi"
uname -a
date
```

验证：

```bash
chmod +x /userdata/hello.sh
/userdata/hello.sh
```

#### 3B. C 程序（二选一）

路线 1：如果板子有 `gcc`，板端直接编译  
路线 2：电脑交叉编译后 `scp` 上传

最小程序：

```c
#include <stdio.h>
int main(void) {
    printf("hello rk3566\n");
    return 0;
}
```

**成功标准：**

- 知道程序放哪（优先 `/userdata`）
- 会赋权执行
- 会区分源码、可执行文件、运行结果

- 已创建 `/etc/init.d/S45wifi-auto`，开机自动启动 `wpa_supplicant` 和 `udhcpc`。
- 手动执行脚本成功，重启后日志出现 `wifi-auto: OK`。
- 重启后 `wlan0` 获得 `192.168.0.106/24`，网关 Ping 成功，并可用 SSH 重新登录。
