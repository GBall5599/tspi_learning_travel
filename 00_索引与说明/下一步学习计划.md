## 3. 下一课：文件、权限与持久化巩固

### 目标

把已经零散使用过的文件和权限知识串成完整判断流程：

```text
文件在哪
→ 谁拥有它
→ 谁能读/写/执行
→ 重启是否还存在
→ 改动是否已经落盘
```

### 3A. 路径和持久性

对比：

```text
/tmp       临时数据，重启可能丢失
/etc       系统配置，通常需要管理员权限
/userdata  用户数据和学习文件，适合持久保存
```

### 3B. 权限

重点命令：

```sh
ls -l
chmod +x
chmod 644
id
whoami
```

理解：

```text
r = read
w = write
x = execute
```

### 3C. 落盘和重启

重点命令：

```sh
sync
reboot
```

通过创建测试文件、修改权限、重启后再次检查，验证：

- 文件是否持久；
- 权限是否持久；
- `/tmp` 和 `/userdata` 的差异；
- 配置修改后为什么要 `sync`。

### 第 4 课成功标准

- 能解释 `/tmp`、`/etc`、`/userdata` 的用途；
- 能读懂 `ls -l` 权限字符串；
- 能用 `chmod` 改变执行权限；
- 能用 `sync` 和 `reboot` 做持久化验证；
- 能区分“命令成功”“文件存在”和“配置已持久化”。
