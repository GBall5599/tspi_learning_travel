## 3. 下一课：显示与 3.1 寸 MIPI 屏

### 3A. 本课目标

先理解和盘点当前 Buildroot 显示链路：

```text
显示控制器（VOP）
  → HDMI 或 MIPI DSI
  → 外部显示设备（显示器 / MIPI 面板）
  → 背光、触摸与用户态 framebuffer / DRM 接口
```

本课第一阶段只读查看现有设备树和 Linux 接口，不直接改 DTS，不烧录 Debian MIPI 镜像。

### 3B. 先补概念

- VOP：Rockchip 显示输出处理器；
- HDMI：常见外接显示接口；
- MIPI DSI：面向嵌入式面板的高速串行显示接口；
- panel：显示面板节点；
- backlight：背光控制节点；
- touch：触摸控制器节点；
- framebuffer / DRM：内核向用户态暴露的显示接口。

### 3C. 安全边界

- 先查看，不改显示设备树；
- 未确认硬件接线、供电和面板时序前，不导出未知 GPIO 或修改背光；
- 不在本阶段烧录 MIPI Debian 镜像；
- 当前 Buildroot 可用串口作为恢复和观察通道。

### 3D. 第 8 课成功标准

- 能定位 VOP、HDMI、MIPI DSI 和显示子系统节点；
- 能区分控制器节点与具体面板节点；
- 能盘点 `/sys/class/graphics`、`/dev/fb*` 或 DRM 接口的实际状态；
- 能说明 HDMI 与 MIPI 面板验证路径的差异；
- 不修改设备树、不改变未知硬件状态。
