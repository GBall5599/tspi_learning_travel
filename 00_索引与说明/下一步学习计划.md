继续遵循：

```text

→ 选择命令/改动
→ 观察结果
```

```text
先查资料和只读状态
→ 确认引脚用途

→ 观察现象
→ 必要时恢复原状态
```

MobaXterm 串口操作继续遵守：

- 每次只输入一条命令；
- 不使用多行 heredoc 粘贴；
- 不直接粘贴包含 `\n` 的长命令；
- 改网络时优先使用串口，避免 SSH 断线后失去控制。

## 3. 下一课：GPIO / 按键 / LED 入门

### 目标

从“会用 Linux”进入“观察和控制硬件”：

```text
系统接口盘点
  → 设备树/板级资料定位
  → 选择安全 GPIO
  → 读取输入或当前状态
  → 最小化控制输出
  → 观察 LED / 按键现象
```

### 3A. 系统接口盘点

只读检查：

```sh
ls -l /dev/gpiochip* 2>/dev/null
```

```sh
command -v gpiodetect
```

```sh
command -v gpioinfo
```

```sh
ls -ld /sys/class/gpio 2>/dev/null
```

实际学习时不必一次粘贴多行，逐条执行并记录结果。

### 3B. 安全边界

在确认引脚用途前，不做以下操作：

- 不随机 `export` GPIO；
- 不随机改变 GPIO 电平；
- 不触碰 eMMC、Wi-Fi 复位、电源选择、MIPI 屏相关引脚；
- 不把 1.8V/3.3V 电源域误当普通 GPIO。

### 3C. 资料定位

本地资料已经找到：

- `02_开发板硬件/wiki/jlceda-project-file-opening.md` 中有“硬件 GPIO 排针”和“GPIO 控制（libgpiod）”章节；
- 下一步需要结合实际 RK3566 板卡原理图/引脚表，确认可安全实验的 LED 或按键。

### 第 5 课成功标准

- 能列出系统提供的 GPIO 设备接口；
- 能定位一个安全的 LED 或按键；
- 先完成只读验证，再进行一次最小控制实验；
- 实验结束后能恢复 GPIO 状态。
