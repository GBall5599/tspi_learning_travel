# SSH 第一课：自己验证系统状态

> 日期：2026-07-24  
> 目标：不再机械照抄命令，而是先想“要验证什么”，再选命令。  
> 前提：已能 `ssh root@192.168.0.x` 进入 `root@taishanpi`

---

## 0. 使用方式

以后优先用 SSH，串口留给：

- 看完整启动日志
- 断网/进不了系统时救急
- 烧录与 Loader 问题

SSH 登录后，你的提示符应类似：

```text
root@taishanpi:~#
```

如果 SSH 连不上：

1. 先串口确认系统是否起来
2. 确认 Wi-Fi 是否还连着
3. 确认当前 IP 是否变化
4. 再重新 `ssh root@当前IP`

## 1. 本课原则

每次只做一件事：

```text
我想知道什么？
  → 应该看系统哪一层？
  → 用哪条命令验证？
  → 结果说明了什么？
```

不要一上来就问“下一条命令是什么”。

---

## 2. 第一组自测题（先自己做）

在 SSH 里完成下面 6 个问题。  
**先自己想命令，做完后再对照文末参考答案。**

### Q1. 这是什么系统、什么内核、什么架构？

你要确认：

- 是不是 Linux
- 内核版本
- 是不是 aarch64
- 主机名

### Q2. 这是 Buildroot 还是别的发行版？

你要确认：

- 发行版名字
- 版本号

### Q3. 2GB 内存现在还剩多少可用？

你要确认：

- total / used / available

### Q4. 根分区和 /userdata 各用了多少？

你要确认：

- `/` 剩余空间
- `/userdata` 是否还在

### Q5. 当前 Wi-Fi IP 是多少？网关能不能通？

你要确认：

- `wlan0` 的 IPv4
- 能否 ping 通 `192.168.0.1`

### Q6. SSH 服务现在是谁在监听 22 端口？

提示：

- 不一定叫 `sshd`
- 可能是 `dropbear`

## 4. 参考命令（先别看，做完再对）

<details>
<summary>点击展开参考，不建议先看</summary>

### Q1

```bash
uname -a
hostname
```

### Q2

```bash
cat /etc/os-release
```

### Q3

```bash
free -h
```

### Q4

```bash
df -h
```

或：

```bash
df -h / /userdata
```

### Q5

```bash
ip -4 addr show wlan0
ping -c 2 192.168.0.1
```

### Q6

```bash
netstat -an | grep :22
ps | grep -E 'dropbear|sshd' | grep -v grep
```

</details>
