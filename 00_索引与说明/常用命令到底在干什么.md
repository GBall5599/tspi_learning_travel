## 0. 先记住一句话

Linux 命令大多不是“魔法”，而是：

```text
向系统提问
或
让系统做一件小事
```

例如：

| 你想知道 | 本质问题 |
|---|---|
| 我是谁 | 内核版本、架构、主机名 |
| 我还有多少内存 | 内存够不够 |
| 磁盘还有多少 | 分区空间够不够 |
| 我联网了吗 | 有没有 IP、网关通不通 |
| SSH 还能不能连 | 22 端口有没有人在听 |

## 1. `uname -a`：我现在跑的是什么内核？

你执行过：

```bash
uname -a
```

结果：

```text
Linux taishanpi 6.1.141 #3 SMP Fri Mar 20 15:39:41 CST 2026 aarch64 GNU/Linux
```

逐段看：

| 字段 | 含义 |
|---|---|
| `Linux` | 内核名字 |
| `taishanpi` | 主机名 |
| `6.1.141` | 内核版本 |
| `SMP` | 支持多核 |
| `aarch64` | 64 位 ARM 架构 |
| `GNU/Linux` | 常见 Linux 用户态环境标识 |

它回答的问题：

```text
板子现在跑的内核是谁？什么架构？
```

它**不回答**：

- 是不是 Buildroot
- 磁盘还剩多少
- 有没有联网

## 2. `cat /etc/os-release`：这是哪个系统发行版？

你执行过：

```bash
cat /etc/os-release
```

结果重点：

```text
NAME=Buildroot
PRETTY_NAME="Buildroot 2024.02"
VERSION_ID=2024.02
RK_BUILD_INFO="... rockchip_rk3566"
```

含义：

```text
这不是 Ubuntu
这不是 Android
这是 Buildroot 2024.02
并且是为 RK3566 构建的
```

对比：

| 命令 | 看什么 |
|---|---|
| `uname -a` | 内核 |
| `/etc/os-release` | 发行版/根文件系统身份 |

可以记：

```text
uname 看内核皮肤下的发动机
os-release 看你现在坐的是什么车
```

## 3. `free -h`：内存还剩多少？

```bash
free -h
```

你的结果：

```text
Mem: total 1.9Gi  used 88Mi  free 1.7Gi  available 1.8Gi
Swap: 0B
```

怎么读：

| 列 | 含义 | 你的情况 |
|---|---|---|
| total | 总内存 | 约 2GB |
| used | 已用 | 很少，88Mi |
| free | 完全空闲 | 1.7Gi |
| available | 实际还能给程序用的 | 1.8Gi |
| Swap | 交换分区 | 没开 |

重点看 `available`，比只看 `free` 更有用。

它回答：

```text
内存紧不紧？
```

## 4. `df -h`：磁盘分区还剩多少？

```bash
df -h / /userdata
```

你的结果：

```text
/dev/root       5.9G  746M  5.0G  13% /
/dev/mmcblk0p8  8.2G  388K  8.2G   1% /userdata
```

怎么读每一列：

| 列 | 含义 |
|---|---|
| Filesystem | 哪个设备/分区 |
| Size | 总大小 |
| Used | 已用 |
| Avail | 剩余 |
| Use% | 使用率 |
| Mounted on | 挂载到哪个目录 |

结论：

```text
系统分区 / ：总共约 5.9G，用了 746M，还剩 5.0G
用户数据 /userdata ：约 8.2G，几乎全空
```

记忆：

```text
free 看内存（RAM）
df 看磁盘（eMMC 分区）
```

## 5. `ip addr` / `ip -4 addr show wlan0`：我有没有 IP？

你看到：

```text
wlan0
inet 192.168.0.106/24
```

含义：

```text
网卡名：wlan0
IPv4：192.168.0.106
网段：192.168.0.x
```

### `UP` 和有 IP 不是一回事

```text
UP = 网卡开关开了
inet = 已经拿到门牌号
```

可能出现：

```text
有 wlan0 且 UP，但没有 inet
→ 还没连上 Wi-Fi，或还没 DHCP
```

你现在两者都有，所以网络地址层是通的。

标准命令建议记这两个：

```bash
ip -4 addr show wlan0
ping -c 2 192.168.0.1
```

## 6. `ping`：这条路通不通？

```bash
ping -c 2 192.168.0.1
```

你的结果：

```text
2 packets transmitted, 2 received, 0% packet loss
```

含义：

```text
发出 2 个包，收到 2 个回复，丢包 0%
板子到路由器网关是通的
```

不同目标测不同层：

| 命令 | 测什么 |
|---|---|
| `ping 127.0.0.1` | 本机网络协议栈 |
| `ping 192.168.0.1` | 到路由器 |
| `ping 8.8.8.8` | 外网 IP |
| `ping baidu.com` | DNS + 外网 |

## 7. Q6 重点：`netstat` 到底是什么？

这是你最困惑的地方，单独讲。

### 7.1 先把命令拆开

```bash
netstat -an | grep ':22'
```

拆成两部分：

#### A. `netstat -an`

意思是：

```text
查看当前网络连接和监听端口列表
```

- `-a`：显示所有相关连接/监听
- `-n`：用数字显示 IP 和端口，不翻译成名字

可以把它想成：

```text
列出板子当前的“网络插座状态”
```

#### B. `| grep ':22'`

竖线 `|` 叫管道，意思是：

```text
把左边命令的输出，交给右边命令继续筛
```

`grep ':22'` 的意思是：

```text
只留下包含 :22 的行
```

所以整句是：

```text
先列出所有网络端口状态
再只看 22 号端口相关的
```

为什么看 22？

```text
SSH 默认就用 22 端口
```

---

### 7.2 你的输出逐行解释

```text
tcp  0  0  0.0.0.0:22   0.0.0.0:*   LISTEN
tcp  0 36  192.168.0.106:22   192.168.0.104:8187   ESTABLISHED
tcp  0  0  :::22        :::*        LISTEN
```

#### 第 1 行：`LISTEN`

```text
0.0.0.0:22 ... LISTEN
```

意思：

```text
板子正在 22 端口“开门等人”
也就是 SSH 服务已经启动，等待连接
```

`0.0.0.0` 表示：

```text
在所有 IPv4 地址上监听
不是只监听某一个网卡
```

#### 第 2 行：`ESTABLISHED`

```text
192.168.0.106:22  192.168.0.104:8187  ESTABLISHED
```

意思：

```text
已经有一条 SSH 连接建立成功了
```

两端分别是：

```text
板子：192.168.0.106 的 22 端口
电脑：192.168.0.104 的 8187 端口
```

所以这一行几乎可以翻译成：

```text
你现在这条 SSH 会话，正在连着
```

#### 第 3 行：IPv6 监听

```text
:::22 ... LISTEN
```

意思：

```text
IPv6 上也在监听 22 端口
```

当前我们主要用 IPv4，可先不深入。

---

### 7.3 那“是谁在监听 22”？

`netstat` 告诉你：

```text
22 端口有人在听
```

但不一定直接告诉你进程名。  
所以还要再问一层：

```bash
ps | grep -E 'dropbear|sshd' | grep -v grep
```

这里：

- `ps`：看进程列表
- `grep dropbear|sshd`：找 SSH 相关进程
- `grep -v grep`：去掉 grep 自己

### 为什么你可能看不到进程名？

Buildroot 上常见是 **Dropbear**。  
有时：

- 进程名不叫 `sshd`
- 或者 `ps` 输出很简略
- 或者服务以守护方式运行，显示不明显

但只要 `netstat` 显示：

```text
:22 LISTEN
```

并且你已经能：

```text
ssh root@192.168.0.106
```

就可以确定：

```text
SSH 服务是活的
```

当前这套镜像里，SSH 服务是 **Dropbear**，启动脚本是：

```text
/etc/init.d/S50dropbear
```

pid 文件通常在：

```text
/var/run/dropbear.pid
```

所以更稳的查法是：

```bash
cat /var/run/dropbear.pid
netstat -an | grep :22
```

## 12. 第 3 课新增命令：文本、权限、参数和时区

### 12.1 `chmod +x`

```sh
chmod +x /userdata/hello.sh
```

给脚本添加执行权限。`ls -l` 中出现 `x` 后，才可以使用 `./hello.sh` 直接运行。

### 12.2 `sed -i`

```sh
sed -i 's/$(data)/$(date)/' /userdata/hello.sh
```

`sed` 是文本处理工具；`-i` 表示直接修改文件；`s/旧/新/` 表示替换。

查看指定行：

```sh
sed -n '1,240p' /bin/list-iodomain.sh
```

`-n` 关闭自动输出，`1,240p` 表示只打印第 1 到第 240 行。没有 `-i`，所以这里只读不改。

### 12.3 `tail`

```sh
tail -n 10 /userdata/hello.sh
```

查看文件最后 10 行，适合检查刚追加的内容。

### 12.4 `grep -R`

```sh
grep -R "list-iodomain" /etc/init.d
```

含义：在 `/etc/init.d` 目录及其子目录中，递归查找包含 `list-iodomain` 的文本行。

下面这部分：

```sh
2>/dev/null
```

表示把错误输出丢弃，避免目录不存在或权限错误刷屏。它不会修改文件。

### 12.5 Shell 参数和退出码

```sh
$?
```

上一条命令的退出状态码。

```sh
$#
```

脚本收到的参数总数。

```sh
$1
```

第一个参数。

### 12.6 `date` 和时区

```sh
date
```

显示当前时间。若输出带 `UTC`，表示当前显示的是 UTC 时区；中国本地时区使用：

```sh
ln -sf /usr/share/zoneinfo/Asia/Shanghai /etc/localtime
echo 'Asia/Shanghai' > /etc/timezone
sync
```

## 13. 命令使用原则

看到命令时，先问自己：

```text
它是查看，还是修改？
它作用于文件、进程、网络还是时区？
它的输出是标准输出，还是错误输出？
执行后应该检查什么结果？
```
