### 3.3 网络与 SSH

- 扫描 Wi-Fi，找到 `ccccc2.4g`
- `wifi-connect.sh` 连接成功
- `udhcpc` 获取 IP
- 验证：
  - 网关可 ping
  - `8.8.8.8` 可 ping
  - `baidu.com` 可 ping（DNS 正常）
- 电脑 SSH 登录成功：
  ```text
  ssh root@192.168.0.x
  ```

### 3.4 概念理解（已过关）

你已经能正确说明：

1. `free -h` 看运行内存，`df -h` 看磁盘空间  
2. `LISTEN` 等待连接，`ESTABLISHED` 已建立连接  
3. `/tmp` 临时，重启丢失；所以 Wi-Fi 配置不能只放 `/tmp`  
4. `ping 8.8.8.8` 测 IP 通路；`ping baidu.com` 还要 DNS  

仍需继续巩固：

- `wlan0 UP` 与 `inet IP` 的区别（已讲解，需多练）
- 重启后如何系统化排查网络
