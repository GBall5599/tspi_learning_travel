### 3.6 概念理解

已经掌握：

1. `free -h` 看运行内存，`df -h` 看磁盘空间；
2. `LISTEN` 表示等待连接，`ESTABLISHED` 表示连接已建立；
3. `wlan0 UP` 只表示网卡启用，还要看 `LOWER_UP` 和 `inet`；
4. `ping 192.168.1.1` 验证到网关的链路；
5. `ping 8.8.8.8` 测 IP 通路，域名 Ping 还涉及 DNS；
6. `$?` 表示上一条命令的退出状态码；
7. `$#` 表示参数数量，`$1` 表示第一个参数；
8. `grep -R` 用于递归搜索文本，`2>/dev/null` 用于隐藏错误输出。

### 3.7 第 8 课：当前 Buildroot 显示链路只读盘点

- `/dev/fb*` 与 `/sys/class/graphics` 不存在，当前不以传统 fbdev 为主要显示接口；
- `/dev/dri/card0`、`renderD128` 和 `/sys/class/drm/card0-HDMI-A-1` 存在；
- HDMI 连接器为 `status: disconnected`、`enabled: disabled`，模式列表为空；
- 运行时设备树中 VOP 与 HDMI 为 `okay`，两个 MIPI-DSI 节点均为 `disabled`；
- `dmesg` 证明 VOP、HDMI 已 bound，Rockchip DRM 已 Initialized；
- 能区分设备树 `status = okay` 与 DRM connector `status = disconnected`；
- 能说明节点存在、驱动匹配、probe/绑定和实际硬件工作不是同一件事；
- endpoint 图目前只要求初步认识，留待设备树进阶课程结合真实 DTS 深入；
- 全程只读，没有接屏、烧录、修改 DTS/sysfs 或操作未知 GPIO。

## 5. 第 2 课与 Wi-Fi 应用复测记录

### 原第 2 课结论

- `/tmp` 中的 Wi-Fi 配置会随重启丢失，不能作为唯一配置位置；
- 有效配置保存到 `/etc/wpa_supplicant.conf`；
- `/etc/init.d/S45wifi-auto` 已启用；
- 重启后会自动启动 `wpa_supplicant` 和 `udhcpc`。

### 2026-07-25 新环境复测

- 备份 `/etc/wpa_supplicant.conf`；
- 通过 `vi` 将配置切换为新 Wi-Fi `ChinaNet-gsZY`；
- `sync` 后停止旧 `wpa_supplicant` 和 `udhcpc`；
- 启动 `/etc/init.d/S45wifi-auto start`；
- 第一次因 RSSI `-98`、距离较远而出现 `NO-CARRIER`；
- 将板子移近路由器后获得 `192.168.1.8/24`；
- 网关 `192.168.1.1` Ping 3/3 成功；
- MobaXterm SSH 登录成功；
- `reboot` 后自动联网，重新 SSH 登录成功。

### 2026-07-29 同名 SSID 与 BSSID 排障应用

- 电脑和开发板均连接 SSID `rskj`，但开发板最初连接 BSSID `DC:D8:7C:28:64:36`；
- 该 AP 的网关为 `192.192.192.192`，开发板获得 `192.192.192.139/24`，与电脑的 `192.168.30.0/24` 不同；
- 通过 `iwconfig`、`ip route`、`ping`、`ip neigh` 和 `iwlist scanning` 确认环境中存在多个同名 AP；
- 主路由器的 5 GHz AP、网关和 2.4 GHz AP 分别为 `...:D3`、`...:D1`、`...:D4`；
- 在 `/etc/wpa_supplicant.conf` 中增加 `bssid=DC:D8:7C:57:74:D4`，锁定主路由器 2.4 GHz AP；
- 修正一次 `bassid` 拼写错误，清理旧 IPv4 地址与路由后重新连接；
- 最终获得 `192.168.30.227/24`，默认网关 `192.168.30.1`；
- 电脑 Ping 5/5 成功，Dropbear TCP 22 可达；
- `reboot` 后 BSSID、IP、路由和 SSH 均恢复正常；
- 完整记录：`00_索引与说明/学习记录/2026-07-29-WiFi同名SSID与BSSID排障记录.md`。
### IO-domain 刷屏说明

`/etc/init.d/S98iodomain.sh` 会在后台每 120 秒运行一次 `/bin/list-iodomain.sh`，读取并打印 RK356x IO 电压域信息。它不是 `hello.sh`，也不影响 SSH/Wi-Fi 主流程；目前保留不修改。
