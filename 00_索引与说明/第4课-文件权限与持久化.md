# 第 4 课：文件、权限与持久化巩固

> 完成日期：2026-07-25  
> 系统：Buildroot 2024.02 + Linux 6.1.141  
> 运行入口：SSH `root@192.168.1.8`

## 1. 本课目标

理解三个常见路径的职责：

```text
/tmp       临时文件系统
/etc       系统配置目录
/userdata  持久化用户数据分区
```

并完成：

```text
创建测试文件
  → 查看文件权限
  → 修改权限
  → sync
  → reboot
  → 检查文件和权限是否保留
```

## 2. 查看挂载关系

```sh
df -h /tmp /etc /userdata
```

本次结果：

```text
tmpfs           ... /tmp
/dev/root       ... /
/dev/mmcblk0p8  ... /userdata
```

结论：

- `/tmp` 使用 `tmpfs`，重启后临时内容通常消失；
- `/etc` 位于根文件系统 `/`；
- `/userdata` 是独立的 eMMC 分区，适合保存用户数据和学习程序。

## 3. 文件持久化实验

创建临时文件：

```sh
echo "tmp test" > /tmp/lesson4-tmp.txt
```

创建持久化文件：

```sh
echo "userdata test" > /userdata/lesson4-userdata.txt
```

查看权限：

```sh
ls -l /tmp/lesson4-tmp.txt /userdata/lesson4-userdata.txt
```

默认权限：

```text
-rw-r--r--
```

即数字权限：

```text
644
```

`echo` 自动追加换行，因此文件大小比可见文字多 1 字节是正常的。

## 4. 修改文件权限

```sh
chmod 600 /userdata/lesson4-userdata.txt
```

再次查看：

```sh
ls -l /tmp/lesson4-tmp.txt /userdata/lesson4-userdata.txt
```

结果：

```text
-rw------- 1 root root ... /userdata/lesson4-userdata.txt
```

`600` 表示：

```text
文件所有者：可读、可写
同组用户：无权限
其他用户：无权限
```

## 5. 保存和重启验证

```sh
sync
```

```sh
reboot
```

重启后检查：

```sh
ls -l /tmp/lesson4-tmp.txt /userdata/lesson4-userdata.txt
```

结果：

```text
/tmp/lesson4-tmp.txt：不存在
/userdata/lesson4-userdata.txt：仍然存在，权限仍为 600
```

读取持久化文件：

```sh
cat /userdata/lesson4-userdata.txt
```

结果仍为：

```text
userdata test
```

## 6. 目录权限和 sticky bit

```sh
ls -ld /tmp /etc /userdata
```

本次结果：

```text
drwxr-xr-x  ... /etc
drwxrwxrwt  ... /tmp
drwxr-xr-x  ... /userdata
```

说明：

- `d` 表示目录；
- `/etc` 和 `/userdata` 通常是 `755`；
- `/tmp` 的 `t` 是 sticky bit；
- `/tmp` 允许多用户创建临时文件，但通常只能删除自己创建的文件。

## 7. `/etc` 配置持久化验证

本课还验证了上一阶段设置的时区：

```sh
ls -l /etc/localtime /etc/timezone
```

结果：

```text
/etc/localtime -> /usr/share/zoneinfo/Asia/Shanghai
```

```sh
cat /etc/timezone
```

结果：

```text
Asia/Shanghai
```

说明 `/etc` 中的配置在重启后仍然保留。

## 8. 本课结论

```text
/tmp 文件：重启后丢失
/userdata 文件：重启后保留
/userdata 权限：重启后保留
/etc 时区配置：重启后保留
sync + reboot：已实践
```
