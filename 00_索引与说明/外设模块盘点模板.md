# 外设模块盘点模板

> 建立日期：2026-07-31
> 用途：在采购新模块前，先盘点现有模块并筛选适合 Linux 驱动课程的硬件

## 1. 填写原则

不要只写“温湿度模块”“陀螺仪”等泛称。应尽量提供：

- 模块名称；
- 主芯片丝印；
- 接口类型；
- 供电和逻辑电平；
- 引脚标注；
- 数量；
- 正面、背面和芯片近照；
- 已知资料或购买链接（如有）。

## 4. 后续分类

收到清单后，为每个模块标记：

| 分类 | 含义 |
|---|---|
| A | 可直接用于当前课程 |
| B | 有用，但需确认电平、接线或驱动资料 |
| C | 功能重复，暂不需要 |
| D | 当前板卡或课程不适合使用 |

再将 A/B 类模块绑定到 I2C、SPI、GPIO/IRQ、PWM、IIO、UART 等具体课程。

## 5. 安全边界

- 未确认逻辑电平前不连接 RK3566 GPIO；
- I2C 模块必须确认上拉电阻接到 3.3V 还是 5V；
- SPI Flash 和传感器优先选择原生 3.3V 逻辑；
- 调试串口保留为恢复通道，UART 实验优先使用第二个 USB-TTL；
- 接线前先对照开发板 IO 分配表、模块数据手册和实物丝印。
