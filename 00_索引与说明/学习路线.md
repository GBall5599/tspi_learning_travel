## 第 5 课完成结果

- 理解普通文件、字符设备、块设备和 `/dev` 设备节点；
- 理解主设备号、次设备号和驱动注册；
- 理解物理 Pin、GPIO 名称、gpiochip、line offset 和 sysfs 全局编号；
- 发现 `/dev/gpiochip0`～`/dev/gpiochip4`；
- 验证旧版 sysfs 的 GPIO3：`base=96`、`ngpio=32`、`label=gpio3`；
- 当前镜像未提供 `gpiodetect/gpioinfo/gpioget/gpioset`；
- 通过 Linux LED 子系统手动控制 `rgb-led-r` 亮灭；
- 将红灯恢复为 `timer`、`delay_on=500`、`delay_off=500`；
- 通过 `evtest /dev/input/event4` 捕获 REC 的 `KEY_RESTART` 按下和释放事件。

## 当前主线：第 6 课 C 用户态程序与交叉编译

目标：

1. 理解源代码、编译器、目标架构和 ELF 可执行文件；
2. 已在 Ubuntu 22.04.5 中安装并验证 `aarch64-linux-gnu-gcc 11.4.0`；
3. 编写最小 `hello.c`；
4. 编译为 AArch64 程序；
5. 上传到开发板 `/userdata`；
6. 使用 `file`、`ldd` 或等价工具检查架构和动态链接；
7. 运行程序并检查退出码；
8. 理解为什么 x86-64 Windows 程序不能直接在 RK3566 上运行。

官方 kernel 6.1 SDK 已下载归档，但本课暂不解压；先用 Ubuntu 的通用 AArch64 工具链完成静态链接 hello 程序，后续再切换到匹配 Buildroot 的 SDK。

## 第 7 课：设备树入门

理解 DTB/DTS、U-Boot、内核和板级硬件描述之间的关系。官方 kernel 6.1 Linux SDK 已下载并通过分卷校验；先阅读和定位节点，真正编译时再放到 Linux 文件系统中解压。

## 第 8 课：显示与 3.1 寸 MIPI 屏

1. 验证 Buildroot 下 HDMI；
2. 使用现有 D310T9362V1 规格书、补丁和 DTSI 学习显示链路；
3. 官方 Debian 3.1 寸 MIPI 镜像已经下载，第 8 课需要快速验证硬件时再烧录；
4. 之后再处理显示、触摸和背光。
