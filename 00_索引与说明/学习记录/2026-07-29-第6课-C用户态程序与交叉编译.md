# 2026-07-29 学习记录：第 6 课 C 用户态程序与 AArch64 交叉编译

## 一、学习目标

在 Ubuntu 22.04.5 开发主机上完成一个最小 C 程序的交叉编译、上传和 RK3566 运行验证。

## 二、环境

```text
开发主机：Ubuntu 22.04.5 LTS x86_64（VMware 桥接网络）
开发板：LCKFB-TSPI-RK3566-2G-16G
板端系统：Buildroot 2024.02 + Linux 6.1.141 aarch64
开发板 IP：192.168.30.227
交叉编译器：aarch64-linux-gnu-gcc 11.4.0
Ubuntu 工作目录：~/workspace/rk3566-lesson6
板端目标目录：/userdata
```

## 三、源程序

创建 `hello.c`：

```c
#include <stdio.h>

int main(void)
{
    printf("hello from RK3566!\n");
    return 0;
}
```

使用 `int main(void)` 明确表示入口函数不接收参数；`return 0` 表示正常结束。

## 四、交叉编译与 ELF 验证

执行：

```bash
aarch64-linux-gnu-gcc -std=c11 -Wall -Wextra -O0 -static -o hello hello.c
```

结果：无报错、无警告，生成 `hello`。

检查：

```bash
file hello
```

结果关键字：

```text
ELF 64-bit
ARM aarch64
statically linked
not stripped
```

在 x86-64 Ubuntu 上直接执行：

```bash
./hello
```

得到：

```text
bash: ./hello: cannot execute binary file: Exec format error
```

这符合预期，说明 Ubuntu 主机与 AArch64 目标程序架构不匹配。

## 五、上传与运行

连通性确认：

```text
ping -c 3 192.168.30.227
3 transmitted, 3 received, 0% packet loss
```

使用 SCP 上传：

```bash
scp hello root@192.168.30.227:/userdata/hello_c
```

上传成功：

```text
100%  626KB  131.4KB/s  00:04
```

板端确认：

```sh
ls -l /userdata/hello_c
```

结果：

```text
-rwx------ 1 root root 641000 Jul 29 16:21 /userdata/hello_c
```

运行：

```sh
/userdata/hello_c
```

输出：

```text
hello from RK3566!
```

紧接着：

```sh
echo $?
```

结果为 `0`。
