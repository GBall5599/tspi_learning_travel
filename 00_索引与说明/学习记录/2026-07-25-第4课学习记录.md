# 2026-07-25 学习记录：第 4 课文件、权限与持久化

## 一、学习目标

- 区分 `/tmp`、`/etc`、`/userdata`；
- 理解文件权限和数字表示；
- 练习 `chmod`；
- 使用 `sync` 和 `reboot` 验证持久化。

## 二、挂载关系

执行：

```sh
df -h /tmp /etc /userdata
```

结果确认：

```text
/tmp       tmpfs
/etc       位于 /dev/root 的根文件系统
/userdata  /dev/mmcblk0p8 独立分区
```

## 三、文件实验

创建：

```text
/tmp/lesson4-tmp.txt
/userdata/lesson4-userdata.txt
```

两者初始权限均为：

```text
-rw-r--r--
```

即：

```text
644
```

将持久化文件改为：

```sh
chmod 600 /userdata/lesson4-userdata.txt
```

结果：

```text
-rw-------
```

## 四、重启验证

执行：

```sh
sync
reboot
```

重启后：

```text
/tmp/lesson4-tmp.txt 不存在
/userdata/lesson4-userdata.txt 仍存在
/userdata/lesson4-userdata.txt 权限仍为 600
```

读取内容仍为：

```text
userdata test
```

## 五、目录权限

执行：

```sh
ls -ld /tmp /etc /userdata
```

观察到：

```text
drwxr-xr-x  /etc
 drwxrwxrwt /tmp
drwxr-xr-x  /userdata
```

重点理解：

- `d` 表示目录；
- `/tmp` 的 `t` 是 sticky bit；
- `/etc` 和 `/userdata` 一般为 `755`；
- 目录的 `x` 表示允许进入/访问目录。

## 六、配置持久化

重启后检查：

```sh
ls -l /etc/localtime /etc/timezone
cat /etc/timezone
```

确认：

```text
/etc/localtime -> /usr/share/zoneinfo/Asia/Shanghai
/etc/timezone  = Asia/Shanghai
```
