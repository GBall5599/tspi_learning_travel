## 二、GPIO 设备盘点

发现：

```text
/dev/gpiochip0～/dev/gpiochip4
```

它们均为字符设备，主设备号 254，次设备号 0～4。

验证：

```text
/sys/dev/char/254:3
→ fe760000.gpio/gpiochip3
```

说明设备号能够将 `/dev/gpiochip3` 关联到内核中的 GPIO3 设备。

## 三、编号理解

掌握：

```text
A组 offset 0～7
B组 offset 8～15
C组 offset 16～23
D组 offset 24～31
```

计算正确：

```text
GPIO3_C2 → gpiochip3 line 18
GPIO4_D5 → gpiochip4 line 29
```

理解物理 Pin 编号只代表 40Pin 接口位置，不能直接作为 line offset。

## 四、新旧 GPIO 接口

```

base=96

```

## 五、RGB LED 实验

发现：

```text
mmc0::
rgb-led-r
rgb-led-g
rgb-led-b
```

红色通道原始状态：

```text
max_brightness=1
trigger=timer
delay_on=500
delay_off=500
```

完成：

```text
timer → none
brightness 0 → 1 → 0
none → timer
```

观察到：

- 红色固定点亮时出现白、紫、红、黄混色；
- 红色关闭后，带红色成分的颜色消失；
- 恢复 timer 后原 RGB 闪烁现象恢复。

最终复查：

```text
trigger=timer
delay_on=500
delay_off=500
```

一次将 `brightness` 拼成 `brightnes`，sysfs 返回 `Permission denied`。理解了 root 也不能在内核管理的虚拟文件系统中创建任意属性。

## 六、按键输入实验

发现输入节点：

```text
/dev/input/event0～event5
```

对应关系：

```text
event0 hdmi_cec_key
event1 fe700030.pwm
event2 rk805 pwrkey
event3 bt-powerkey
event4 adc-keys
event5 rk-headset
```

使用：

```sh
evtest /dev/input/event4
```

短按一次 REC，捕获：

```text
KEY_RESTART value 1 → 按下
KEY_RESTART value 0 → 释放
```

按压持续约 208 ms，随后使用 `Ctrl+C` 正常退出。
