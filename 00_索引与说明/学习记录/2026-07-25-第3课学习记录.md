## 三、第 3 课：创建第一个用户态程序

### 1. 创建和检查

在 `/userdata` 中创建：

```text
/userdata/hello.sh
```

脚本输出：

- 固定欢迎语；
- 当前用户；
- 当前目录；
- 当前时间；
- 参数数量；
- 第一个参数。

### 2. 运行方式

先用解释器运行：

```sh
sh /userdata/hello.sh
```

随后添加执行权限：

```sh
chmod +x /userdata/hello.sh
```

再直接运行：

```sh
./hello.sh
```

### 3. 退出码

成功运行后：

```text
exit code=0
```

执行不存在路径：

```sh
ls /not_exist
```

得到：

```text
exit code=2
```

### 4. 命令行参数

```sh
./hello.sh lesson3
```

得到：

```text
argument count: 1
first argument: lesson3
```

```sh
./hello.sh one two three
```

得到：

```text
argument count: 3
first argument: one
```

### 5. MobaXterm 粘贴问题

多行粘贴和包含 `\n` 的 `printf` 命令曾把脚本内容破坏成 `/necho`，并造成重复行。

处理方法：

- 使用 `sed -i` 清理错误行；
- 使用单行 `echo '...' >> 文件` 逐行补回；
- 后续串口操作全部一条命令一条命令执行。

## 四、新环境 Wi-Fi 与 SSH 验证

### 1. 修改前保留备份

```sh
cp /etc/wpa_supplicant.conf /etc/wpa_supplicant.conf.bak
```

通过 `vi /etc/wpa_supplicant.conf` 修改新 Wi-Fi 的 `ssid` 和 `psk`，随后执行：

```sh
sync
```

### 2. 手动重新连接

串口中停止旧进程：

```sh
killall wpa_supplicant 2>/dev/null
```

```sh
killall udhcpc 2>/dev/null
```

启动已有自动联网脚本：

```sh
/etc/init.d/S45wifi-auto start
```

第一次连接日志中出现短暂成功后断开，并且 RSSI 为 `-98`，随后 `wlan0` 为 `NO-CARRIER`，没有 IPv4 地址。

把开发板移到路由器附近后，重新检查：

```sh
ip addr show wlan0
```

最终获得：

```text
inet 192.168.1.8/24
```

### 3. 验证路由和网关

```sh
ip route
```

确认：

```text
default via 192.168.1.1 dev wlan0
```

```sh
ping -c 3 192.168.1.1
```

结果为 3 个包全部收到，丢包率 0%。

### 4. SSH 验证

电脑端使用 MobaXterm 登录：

```text
root@192.168.1.8
```

进入后执行 `whoami`，返回：

```text
root
```

### 5. 重启验证

SSH 中执行：

```sh
sync
```

```sh
reboot
```

重启后串口检查：

```sh
ip addr show wlan0
```

仍然获得：

```text
inet 192.168.1.8/24
```

随后重新 SSH 登录成功，并在 SSH 中运行：

```sh
cd /userdata
./hello.sh ssh
```

说明 Wi-Fi 自动连接、DHCP、SSH 和用户态程序均已恢复。

## 五、时区校准

最初 `date` 输出带有：

```text
UTC
```

检查发现：

```text
/etc/localtime -> ../usr/share/zoneinfo/Etc/UTC
```

确认系统存在：

```text
/usr/share/zoneinfo/Asia/Shanghai
```

切换时区：

```sh
ln -sf /usr/share/zoneinfo/Asia/Shanghai /etc/localtime
```

同步文字配置：

```sh
echo 'Asia/Shanghai' > /etc/timezone
```

保存：

```sh
sync
```

最终 `date` 显示：

```text
Sat Jul 25 20:08:19 CST 2026
```
