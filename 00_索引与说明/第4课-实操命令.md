# 第 4 课实操命令：文件、权限与持久化

> 完成日期：2026-07-25

以下命令请在 SSH 中一条一条执行。

## 1. 查看路径所在分区

```sh
df -h /tmp /etc /userdata
```

## 2. 创建测试文件

```sh
echo "tmp test" > /tmp/lesson4-tmp.txt
```

```sh
echo "userdata test" > /userdata/lesson4-userdata.txt
```

## 3. 查看文件权限

```sh
ls -l /tmp/lesson4-tmp.txt /userdata/lesson4-userdata.txt
```

## 4. 修改权限为 600

```sh
chmod 600 /userdata/lesson4-userdata.txt
```

```sh
ls -l /tmp/lesson4-tmp.txt /userdata/lesson4-userdata.txt
```

## 5. 保存并重启

```sh
sync
```

```sh
reboot
```

## 6. 重启后检查

```sh
ls -l /tmp/lesson4-tmp.txt /userdata/lesson4-userdata.txt
```

```sh
cat /userdata/lesson4-userdata.txt
```

## 7. 查看目录权限

```sh
ls -ld /tmp /etc /userdata
```

## 8. 查看 `/etc` 时区配置

```sh
ls -l /etc/localtime /etc/timezone
```

```sh
cat /etc/timezone
```

## 9. 结果判断

预期：

```text
/tmp/lesson4-tmp.txt 不存在
/userdata/lesson4-userdata.txt 存在
/userdata/lesson4-userdata.txt 权限为 -rw-------
文件内容为 userdata test
/etc/timezone 内容为 Asia/Shanghai
```
