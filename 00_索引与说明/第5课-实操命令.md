# 第 5 课实操命令：GPIO、按键与 LED

> 完成日期：2026-07-26  
> 以下命令在开发板 SSH 中逐条执行。

## 1. GPIO 字符设备

```sh
ls -l /dev/gpiochip* 2>/dev/null
```

```sh
command -v gpiodetect
```

```sh
command -v gpioinfo
```

```sh
command -v gpioget
```

```sh
command -v gpioset
```

未找到命令时立即查看退出码：

```sh
echo $?
```

## 2. 旧版 GPIO sysfs

```sh
ls -ld /sys/class/gpio 2>/dev/null
```

```sh
ls -l /sys/class/gpio
```

```sh
cat /sys/class/gpio/gpiochip96/base
```

```sh
cat /sys/class/gpio/gpiochip96/ngpio
```

```sh
cat /sys/class/gpio/gpiochip96/label
```

```sh
ls -l /sys/dev/char/254:3
```

注意：本课不向 `/sys/class/gpio/export` 写入未知 GPIO 编号。

## 3. LED 只读盘点

```sh
ls -l /sys/class/leds 2>/dev/null
```

```sh
ls -l /sys/class/leds/rgb-led-r/
```

```sh
cat /sys/class/leds/rgb-led-r/max_brightness
```

```sh
cat /sys/class/leds/rgb-led-r/brightness
```

```sh
cat /sys/class/leds/rgb-led-r/trigger
```

```sh
cat /sys/class/leds/rgb-led-r/delay_on
```

```sh
cat /sys/class/leds/rgb-led-r/delay_off
```

## 4. 红色 LED 手动控制

停止自动触发：

```sh
echo none > /sys/class/leds/rgb-led-r/trigger
```

手动点亮：

```sh
echo 1 > /sys/class/leds/rgb-led-r/brightness
```

读取确认：

```sh
cat /sys/class/leds/rgb-led-r/brightness
```

手动熄灭：

```sh
echo 0 > /sys/class/leds/rgb-led-r/brightness
```

## 5. 恢复红色 LED

```sh
echo timer > /sys/class/leds/rgb-led-r/trigger
```

```sh
cat /sys/class/leds/rgb-led-r/trigger
```

```sh
cat /sys/class/leds/rgb-led-r/delay_on
```

```sh
cat /sys/class/leds/rgb-led-r/delay_off
```

最终应恢复：

```text
trigger   = timer
delay_on  = 500
delay_off = 500
```

```sh
cat /proc/bus/input/devices
```

```sh
command -v evtest
```

## 7. REC 按键测试

```sh
evtest /dev/input/event4
```

进入测试后只短按一次 REC，看到 `KEY_RESTART` 的 `value 1` 和 `value 0` 后按 `Ctrl+C` 退出。

安全要求：

- 不按 RST；
- 不测试 PWR；
- 不同时按 REC 和 RST；
- 不长按 REC 后重启或复位。
