# LCKFB 泰山派 RK3566 学习资料库

本目录面向：

- **LCKFB-TSPI-RK3566-2G-16G**（立创·泰山派 2G+16G 版本）
- **LCKFB MIPI 3.1inch Screen**（D310T9362V1，480×800）

## 当前进度（2026-07-26）

已完成：

- 串口调试、Loader 烧录、Buildroot 启动；
- 手动 Wi-Fi、DHCP、网关、外网和 SSH；
- 第 2 课：Wi-Fi 开机自动重连；
- 第 3 课：第一个用户态程序；
- 第 4 课：文件、权限与持久化巩固；
- 第 5 课：GPIO、按键与 LED 入门；
- 更换 Wi-Fi 后重连、重启自动联网、SSH 复连；
- 开发板时区切换为 `Asia/Shanghai`。

当前环境：

```text
Wi-Fi：ChinaNet-gsZY
开发板 IP：192.168.1.8
网关：192.168.1.1
时区：Asia/Shanghai
```

当前阶段判断：

- 嵌入式 Linux 入门前半段已完成；
- 已从“板卡启动与系统使用”过渡到“硬件接口与应用开发”；
- 第 5 课已完成，下一课为第 6 课：第一个 C 用户态程序与交叉编译；
- 官方 kernel 6.1 SDK 分卷和 Debian 3.1 寸 MIPI 镜像已下载；第 6 课无需解压 SDK，先使用独立 AArch64 交叉工具链。
