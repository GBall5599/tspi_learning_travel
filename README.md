# LCKFB 泰山派 RK3566 学习资料库

本目录面向：

- **LCKFB-TSPI-RK3566-2G-16G**（立创·泰山派 2G+16G 版本）
- **LCKFB MIPI 3.1inch Screen**（D310T9362V1，480×800）

## 当前进度（2026-08-03）

已完成：

- 串口调试、Loader 烧录、Buildroot 启动；
- 手动 Wi-Fi、DHCP、网关、外网和 SSH；
- 第 2 课：Wi-Fi 开机自动重连；
- 第 3 课：第一个用户态程序；
- 第 4 课：文件、权限与持久化巩固；
- 第 5 课：GPIO、按键与 LED 入门；
- 第 6 课：第一个 C 用户态程序与 AArch64 交叉编译；
- 第 7 课：设备树入门（LED、REC 按键与启动参数只读验证）；
- 第 8 课：当前 Buildroot 显示链路只读盘点与概念问答验收；
- 更换 Wi-Fi 后重连、重启自动联网、SSH 复连；
- 完成同名 SSID、多 BSSID、跨网段 DHCP 排障，并锁定主路由器 2.4 GHz AP；
- 开发板时区切换为 `Asia/Shanghai`。

当前环境：

```text
Wi-Fi：rskj
开发板 IP：192.168.30.227
网关：192.168.30.1
2.4 GHz BSSID：DC:D8:7C:57:74:D4
串口：COM10 @ 1500000，8N1，无流控
时区：Asia/Shanghai
```

当前阶段判断：

- 已建立长期使用的 Linux 开发主机：Windows + VMware Workstation Pro + Ubuntu 22.04.5 LTS；
- Ubuntu 与泰山派处于同一桥接网段，已再次确认 Ping 与 SSH 正常；
- 通用 AArch64 交叉编译器 `aarch64-linux-gnu-gcc 11.4.0` 已安装并验证；
- 第 6 课已完成：在 Ubuntu 上交叉编译静态 AArch64 ELF，通过 SCP 上传并在 RK3566 上成功运行；
- 第 7 课已完成：从运行时设备树验证 `gpio-leds`、`adc-keys`、`KEY_RESTART` 和启动参数链路；
- 第 8 课已完成：确认当前系统使用 DRM，VOP 与 HDMI 已绑定，HDMI 连接器为 `disconnected`，两个 MIPI-DSI 节点均为 `disabled`；
- 已完成第 8 课概念复盘与逐题验收；`endpoint` 图留待设备树进阶课程结合真实 DTS 深入；
- 官方 kernel 6.1 SDK 分卷和 Debian 3.1 寸 MIPI 镜像已下载；下一步是第 9 课官方 MIPI 镜像硬件基线，尚未开始烧录。
